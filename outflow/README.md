# Outflow 2.1.7

Local-first income / outflow ledger for GitHub Pages at `/outflow/`.

- Face ID / device biometrics unlock (no password)
- Theme (Auto/Light/Dark) and font size (Small/Medium/Large) in Settings
- Home ledger groups same date + category (+ income/outflow)
- Recurring expense tab for subscriptions / next-due bills
- Daily HKD FX in Settings (not shown on Home)
- JSON backup only — no Excel

Private ledger data stays in the browser. Never commit vault, ledger, or spreadsheet files.
